# Yuwen Fu — 个人作品集网站

一个纯静态网站（无需服务器、无需安装任何东西），布局参考 Chirpy 风格：
左侧边栏 + 顶部搜索 + 首页作品列表 + Categories / Archives + 交互式 Resume + About。
界面支持 **中文 / English** 切换。
自带 **在线编辑器**，改内容、加作品、传图片都在浏览器里完成，一键发布到 GitHub Pages。

```
index.html   页面框架
styles.css   网站样式
app.js       网站逻辑（路由、渲染、Markdown、视频嵌入、中英文界面文字）
data.js      ← 所有内容（简历、作品、个人信息）。编辑器会自动改写这个文件
editor.js    编辑器（只有地址带 ?edit 时才加载，访客看不到）
editor.css   编辑器样式
fonts/       网站字体（放在仓库里，国内也能加载）
vendor/      Markdown 渲染库 marked（同上）
assets/      你上传的图片/短视频（第一次用编辑器上传时自动创建）
```

### 正文里怎么放图片和视频

| 想要 | 做法 |
|---|---|
| 图片 / GIF | 工具栏 **🖼 Image** 上传（大图会自动压缩），或直接 **Ctrl+V 粘贴截图** |
| 短视频片段（≤25 MB） | 工具栏 **🎞 Clip** 上传 MP4/WebM |
| B站 / YouTube / Vimeo | 工具栏 **▶ Video link**，或把视频链接单独放一行 → 自动变成播放器 |
| 小标题 | `## 标题`（会自动出现在右侧目录） |
| 链接 | `[文字](https://...)` |

长视频建议传视频网站再贴链接（GitHub 单个文件不宜太大）。
**国内打不开 YouTube**：重要的视频最好同时传一份到 B站，在正文里放 B站链接（B站播放器国内外都能看）。
YouTube 播放器下方会自动出现一行“在 YouTube 中打开”的链接，播放器加载不出来时访客也能看到视频地址。

## 中英双语

- **界面语言**：右上角 `EN | 中文` 按钮。第一次访问时按浏览器语言自动选，之后会记住访客的选择。
- **专门的链接**：发给国内的人用 `https://wendyfu004.github.io/YuwenFu/?lang=zh`，发给国外的人用 `?lang=en`。打开后直接是对应的语言。
- **文章**：编辑器里每篇文章下面有“中文版本（可选）”一栏，包括标题、摘要和正文。
  - 填了中文版：选中文的访客看到中文版，文章顶部还会出现 English / 中文 切换。
  - 没填：选中文的访客看到英文原文，上方有一行提示“本文暂无中文版”。
  - 只写中文的文章：直接把中文写在上面的主字段里就行。
- **个人资料 / About / 页脚**：Profile 和 Site 页里带“· 中文”的字段。不填就显示英文。
- **分类名**：Site 页的“Category names in Chinese”，每行一个，格式为 `Work = 工作`。
- **简历**：编辑器 Resume 页里每一项都有“· 中文”字段（已预先翻译好，可以自己修改）。选中文的访客看到的是中文简历，包括交互版和文档版。

## 简历 PDF（中英文各一份）

编辑器 Resume 页最上面有两个上传位：**English PDF** 和 **中文 PDF**。
- 上传了文件：访客点 **Download PDF / 下载 PDF**，下载的就是你上传的文件。按钮下方还有一个小链接，可以下载另一种语言的版本。
- 没上传：点按钮会打开打印窗口，打印对应语言的文档版。在打印窗口里选 **另存为 PDF**（A4，一页）即可。
- 目前 `assets/resume-zh.pdf` 是根据中文翻译自动生成的；英文位还空着，等你上传自己的英文 PDF。

## 常见问题

- **发布后网站没变？** GitHub Pages 需要约 1 分钟部署，浏览器也可能有缓存，按 Ctrl+F5 刷新。
- **Publish 报 401/403？** token 过期或权限不对，重新建一个。
- **Publish 报 409？** 仓库是空的，先上传网站文件。
- **想放弃没发布的修改？** Site → **Discard draft**。
